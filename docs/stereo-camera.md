## 使用原视觉页面

打开 `build/gui/rov_ui.exe`，进入原导航中的“视觉”页，来源默认是“机器人双目”。
地址默认 `192.168.20.70`，图像端口默认 `9001`；点击“启动预览”后主动连接 Nano。
地址与端口会保存，应用重启后需要重新点击启动。无需安装 ROS。

原预览区现在按“左目 / 右目”左右并排、等比例显示，两目源于同一张拼接 JPEG。
Nano 已先旋转完整画面 180° 并安排好输出左右目，上位机不再旋转或交换两目。
“保存当前帧”仍保留，保存完整的左右拼接图；不是向 Nano 发送保存命令。

来源切换到“本机相机”后，仍使用原 DirectShow 枚举、选择和预览功能。
切换来源会停止上一个相机来源。原机器人运动按钮及视觉算法请求入口保留；
去畸变、折射校正、检测、位姿算法并未因本次接入而实现。转发画面当前未标定、未矫正。

原 MCU / CAN / 传感器连接在“设置”页管理，端口是 `9000`。
两个连接独立：看图不需要先连接 MCU，停止相机不会关闭 MCU；
相机连接不会发送控制命令，也不会把 JPEG 送入 MCU 的串口解析器。

## 连接与显示状态

| 状态 | 页面行为 |
| --- | --- |
| 未启动 / 已停止 | 可启动预览，画面与保存按钮清空 |
| 正在连接相机 | 可以停止并取消连接；地址和端口暂不可编辑 |
| 等待相机画面 | TCP 已建立，但尚无有效图像；不显示旧图 |
| 双目画面接收中 | 显示左右图、实际尺寸、本机解码帧率和最后帧编号 |
| 画面超时 | 连续 2 秒无新有效帧，清除图像并禁用保存；TCP 可以仍连着 |
| 相机断开，N 秒后重连 | 清空所有连接内缓存，按 1、2、5 秒重试，上限 5 秒 |

重连成功收到有效帧后恢复画面。序号允许跳号，节点重启也可以从 1 重新开始。
“停止”在连接中、无图、超时和重连期间都可用，取消自动重连。
切换导航页面时保留相机接收，隐藏期间跳过图像重绘；返回视觉页显示最新图像。
关闭主窗口会停止相机并退出后台线程。

图像新鲜度取 Windows 本地单调时钟；不把 Nano 的 `receipt_ns` 与 Windows 系统时间相减。
“标称帧率”是 Nano 输出目标 30 FPS，“实时帧率”是本机成功解码速率；两者分开显示。

## 接收与解码边界

依据配套 ROS 2 工程 `docs/deployment/stereo-camera-host-report.md`（2026-10-09）的 UWSC v1 契约：

```text
Nano :9001 → 独立 QTcpSocket → StereoCameraParser
          → StereoCameraService 后台 JPEG 解码
          → 最新图像邮箱 → MainWindow → 原 VisionPage
```

- 40 字节固定帧头，magic 为 `UWSC`；多字节整数使用网络大端序。
- version=1、flags=1、reserved=0；JPEG 长度 1～8,388,608 字节。
- 完整图宽 2～8192 且必须为偶数，高 1～4096。
- Protocol 层增量处理半包和连续多帧，每次只缓存当前帧；上限为 40 字节 + 8 MiB。
- 独立 socket 的读缓冲有同样上限，单次读取最多 64 KiB；每次事件最多处理 1 MiB。
- 网络工作线程保持接收，另一个线程解码 JPEG；解码时仅允许一个活动任务和一个最新待解码帧。
- 先验证 JPEG 起止标记与内部尺寸，再解码并再次校验尺寸，随后在服务层拆分左右目；
  缺少 JPEG 结束标记时拒绝，即使底层解码库可能容忍截断图像。
- GUI 以约 33 ms 的定时器消费单个最新图像邮箱，不累计每帧的排队信号。
- 帧头或实际解码失败时关闭相机连接，清空缓存，再按重连策略重试。
- 每次断开或停止增加会话代号，旧会话中尚未完成的解码结果不能覆盖新连接。
- socket 明确使用 `NoProxy`，不修改系统代理。图像服务没有应用字节发送入口。

TCP/JPEG 没有本项目额外的校验和；无法保证发现仍能正常解码的所有图像内容损坏。

## 构建和运行库

继续使用锁定 Qt 5.15.19 / MinGW 8.1.0，不引入 Qt Multimedia、OpenCV 或新 SDK。
构建主程序时，CMake 自动将 `Qt5Network.dll`、`Qt5Concurrent.dll` 和
`imageformats/qjpeg.dll` 放到主程序旁；现有基本 Qt/MinGW 部署保持原流程。

也可单独补齐相机运行库：

```powershell
& .\tools\deploy-camera-runtime.ps1
# 对隔离测试目录部署：
& .\tools\deploy-camera-runtime.ps1 -AppDirectory .\build\test\gui
```

编译缓存、测试和证据只使用 `build/test/`，`build/gui` 始终只保留主程序及必要运行库。
