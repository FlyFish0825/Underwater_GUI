# ROV UI team guide

The integrated specification in `agent/ROV Qt 上位机集成版统一规范与Agent提示词 v2.1-integrated.md`
is the authoritative visual and collaboration reference. The public build
uses the versions recorded in `docs/toolchain.md`, not the older candidate
versions quoted in the historical source text.

The current delivery is the shared public skeleton: one Qt Widgets main
window, one stacked page container, shared theme/navigation/footer, five
reference-aligned page frames, a Settings placeholder, contracts, and
deterministic preview data. Real communication and device-side work remain
out of scope.
