# ROV 上位机开发说明

本文是日常开发的统一入口，合并了原有的框架、页面契约、依赖、工具链和 UI 协作说明。
协议字段和通信细节以 `agent/ROV上位机通信协议与分层架构规范_v1.0.md` 与源代码为准；
架构图、曲线、科研记录和 Bootloader 使用各自的专题文档。

## 工程边界

本工程是 Windows 上运行的 Qt Widgets ROV 上位机，不包含 Nano、Ubuntu、ARM64、JetPack、
MCU 或设备端工具链。

正式依赖方向如下：

```text
页面 / UI → MainWindow / 契约 → 服务 / 数据 → 协议 → 传输
```

- `src/communication/transport`：USB CDC 与串口字节收发。
- `src/communication/protocol`：AA55 网关、Observer Motor 等纯协议编解码。
- `src/communication/service`、`src/communication/bootloader`：会话、发送队列、升级服务。
- `src/data/services`：解析后的状态、快照和本机相机采集。
- `src/contracts`：可复制的页面快照和用户请求。
- `src/pages`：独立 QWidget，只负责显示快照和发出类型化请求。
- `src/app/MainWindow`：页面装配、全局连接和请求路由。

页面不得直接访问串口、解析 CAN ID、DLC、字节偏移或 CRC；协议层不得依赖 QWidget；传输层
不得直接更新界面。未知值显示 `--`，不能以 0 代替缺失数据。设备反馈、用户目标和用户请求
必须分开表示。

## 页面与交互约定

工程只有一个 `rov::MainWindow`、一个 `QStackedWidget`，固定页面为：

```text
dashboard → motor_debug → firmware → manipulator → vision → settings
```

正式页面采用 `rov::*Page`，构造函数使用 `explicit XxxPage(QWidget *parent = nullptr)`；输入为
`setSnapshot(const XxxSnapshot&)`，输出为类型化 `...Requested` 信号。跨线程只传递 Qt 信号和
可复制快照，所有 QWidget 更新都在 GUI 线程完成。

视觉页默认通过独立 `StereoCameraService` 接收 Nano `9001` 的 UWSC v1 拼接 JPEG，后台解码后
在原预览区等比例并排显示左右目；与 MCU `9000` 连接分开管理，见 [双目相机接入](stereo-camera.md)。
本机来源继续通过 `CameraCaptureService` 使用 Windows DirectShow 枚举摄像头、采集 RGB24 帧、显示
实时画面和保存当前帧。页面只发出相机和六自由度控制请求，由 `MainWindow` 路由；图像去畸变、
折射校正、目标检测和位姿算法仍待接入。运动控制按钮使用“按住运动、松开归零”，切页或应用
失焦时也会发出全零请求。

界面沿用浅色科研工业风格：白灰背景、深蓝文字、蓝色主操作、绿橙红状态色。参考截图只用于
校准布局，不应作为页面图片资源。

## 当前依赖

| 组件 | 固定版本或来源 | 用途与构建方式 |
| --- | --- | --- |
| Qt | 5.15.19，`toolchain/qt/5.15.19` | Core、Gui、Widgets、Concurrent、PrintSupport；通过 `find_package(Qt5 5.15 ...)` 使用。 |
| Windows DirectShow | Windows 系统组件 | 相机枚举、RGB24 取帧和预览；链接 `ole32`、`oleaut32`、`strmiids`、`uuid`。 |
| Fluent-Qt | v1.8.4，`third_party/Fluent-Qt` | 公共按钮、输入框和进度控件；CMake 目标 `FluentQt::FluentQt`，MIT。 |
| Qwt | 6.3.1，`third_party/qwt-6.3` | 电机调试曲线、图例、缩放和平移；静态链接到 `rov_page_motor_debug`，Qwt License 1.0。 |

QCustomPlot、Qt Charts 和 ImPlot 只做过调研，未接入，不能写入 CMake、安装脚本或发布清单。
新增依赖时必须记录上游来源、固定版本、用途、链接目标、许可证、部署影响和最小验证结果；
同时更新 `third_party/README.md`。

## 固定工具链

| 工具 | 版本 | 位置 |
| --- | ---: | --- |
| Qt | 5.15.19 | `toolchain/qt/5.15.19` |
| MinGW GCC/G++ | 8.1.0 POSIX SEH x64 | `toolchain/mingw/8.1.0/Tools/mingw810_64` |
| CMake | 3.28.6 | `toolchain/cmake/3.28.6/cmake-3.28.6-windows-x86_64` |
| Ninja | 1.11.1 | `toolchain/ninja/1.11.1` |
| clangd / clang-format | 14.0.6 | `toolchain/llvm/14.0.6` |

PowerShell 激活环境：

```powershell
. 'toolchain/env/activate.ps1'
```

命令提示符激活环境：

```bat
call toolchain\env\activate.cmd
```

使用固定工具链构建：

```powershell
& 'tools/build-gui.ps1' -BuildType Release
```

构建缓存和所有测试输出在 `build/test/gui`，主程序在 `build/gui/rov_ui.exe`。
`build/gui` 必须只保留可打包运行文件；CMake 禁止在此目录配置或生成缓存。
新版构建脚本部署 Qt/MinGW、Network/Concurrent、Windows 平台与 JPEG 插件，
测试平台插件只部署到 `build/test`。目录规则覆盖历史 `build-test` 约定。
打包与校验见 [干净运行包说明](runtime-package.md)。本机工具链、`build/`、缓存和日志不提交。

## 验证要求

每次 C++ 修改至少运行：

```powershell
& 'tools/build-gui.ps1' -BuildType Debug -RunTests
git diff --check
```

涉及 C++ 跳转或编译数据库时，再运行：

```powershell
& 'toolchain/llvm/14.0.6/bin/clangd.exe' `
  --check=src/app/MainWindow.cpp `
  --compile-commands-dir=build/test/gui `
  --query-driver='toolchain/mingw/8.1.0/Tools/mingw810_64/bin/*' --log=error
```

构建通过不等同于真实硬件联调；涉及相机、串口、CAN 或升级时，交付说明必须分别写明已验证和未验证项。
